# news-explorer-backend

Este proyecto consiste en el backend para una página web, estilo "red social" para viajeros. Utiliza CSS, HTML, Javascript, Express, Winston para manejar la funcionalidad, la cual incluye rutas que manejan los usuarios y sus tarjetas, por otra parte hay rutas para el registro de usuarios y el inicio de sesión. Se utiliza MongoDB (mongoose) para manejar los datos de los usuarios. Se implementan middlewares y dependencias para manejar la autenticación, la seguridad y los registros.

Se implementa una API funcional implementada en un servidor, el cual está vinculado a un dominio que trabaja con HTTPS.
